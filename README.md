# Inventory & Stock Performance Dashboard

##  Project Overview

This project presents an interactive Power BI dashboard designed to analyze inventory and stock performance. It provides insights into stock levels, sales quantities, inventory value, reorder requirements, stockouts, lead times, warehouse performance and product categories to support effective inventory and supply chain decision-making.

##  Key KPIs

- Total Stock Quantity - 443K
- Total Sales Quantity - 135K
- Inventory Value - 56M
- Reorder Products - 58
- Average Lead Time - 6.51
- Stockout Products - 54
- Average Unit Cost - 140.93

##  Dashboard Analysis

The dashboard includes analysis of,

- Stock levels by product
- Sales quantity by product
- Stock distribution by warehouse
- Stock levels by product category
- Monthly stock trends
- Monthly sales trends
- Sales performance by category
- Reorder requirements
- Stockout monitoring
- Inventory value and unit cost
- Lead time performance

##  Key Insights

- The dashboard identifies products that require replenishment through reorder monitoring.
- Stockout analysis highlights products that may require immediate inventory attention.
- Warehouse-level analysis provides visibility into stock distribution across locations.
- Monthly stock and sales trends help compare inventory availability with product demand.
- Category-level analysis supports inventory planning and product performance evaluation.
- Lead-time monitoring can help identify opportunities to improve replenishment efficiency.
